# StudyNook 📚

**StudyNook** is a study room booking platform that helps students find and book suitable study spaces easily. Users can explore available rooms, view room details, and manage their bookings through a simple and responsive interface.

🌐 **Live Website:** https://studynook-frontend-nine.vercel.app/

## ✨ Features

- 🏠 **Responsive Homepage:** Explore study rooms through a modern and user-friendly interface.
- 🔍 **Browse Study Rooms:** View available study rooms with images, descriptions, seating capacity, floor information, and hourly rates.
- 🔐 **Secure Authentication:** Sign up and log in using email or Google authentication.
- ➕ **Add Study Rooms:** Authenticated users can add new study rooms with relevant information and amenities.
- 📝 **Manage Listings:** Room owners can view, edit, and delete their own room listings.
- 📅 **Room Booking:** Book study rooms by selecting a date and time.
- 💰 **Booking Cost Calculation:** Calculate the booking cost based on the selected duration and hourly rate.
- 📋 **My Bookings:** View and manage personal booking information.
- 📱 **Responsive Design:** Enjoy a consistent experience across desktop, tablet, and mobile devices.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd sturdynook-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the project root and configure the required environment variables for authentication and the backend API.

### 5. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
